# Property F implies weak integrality

A Lean 4 formalization, built on Mathlib, of the main theorem of the paper in [`paper/`](paper/).

> Let C be a braided fusion category over ℂ that admits a pseudo-unitary Galois conjugate. If C has
> property F, then C is weakly integral: its global Frobenius–Perron dimension is an integer.

The theorem is `PropertyF.Ground.target` in
[`PropertyF/Ground/Final.lean`](PropertyF/Ground/Final.lean). It proves `PropertyF.Ground.TargetStatement`,
which is stated in [`PropertyF/Ground/Target.lean`](PropertyF/Ground/Target.lean):

```lean
def TargetStatement : Prop :=
  ∀ C : BraidedFusionCategory.{v,u},
    HasPseudoUnitaryGaloisConjugate C → HasPropertyF C.Obj →
      WeaklyIntegral (globalFPDimension C)
```

The proof is complete. There is no `sorry`, the theorem has no additional hypotheses, and it depends
only on the standard axioms:

```text
#print axioms PropertyF.Ground.target
-- [propext, Classical.choice, Quot.sound]
```

## Definitions

Every notion in the statement is defined from Mathlib's category theory in `Target.lean`, with no
numerical data supplied as hypotheses.

- **Braided fusion category.** A braided, abelian, ℂ-linear, rigid monoidal category with
  finite-dimensional hom spaces, a simple unit, and finitely many simple objects up to isomorphism,
  through which every object decomposes.
- **Frobenius–Perron dimension.** The spectral radius of the fusion matrix, built from hom-space
  dimensions. The global FP dimension is the sum of the squares over the simple objects.
- **Global dimension and pseudo-unitarity.** The squared norms |X|² are computed through the braiding's
  canonical double-dual isomorphism, so no pivotal structure is assumed. A category is pseudo-unitary
  when its global dimension equals its global FP dimension.
- **Galois conjugate.** A braided monoidal equivalence that is σ-semilinear on morphisms, for some
  automorphism σ of ℂ.
- **Property F.** For every object X and every n, the subgroup of Aut(X^⊗n) generated by the adjacent
  braidings is finite.

## Proof outline

1. A pseudo-unitary fusion category carries a positive spherical structure, with categorical dimensions
   equal to FP dimensions (`Dimensions`, `CentreInduction`).
2. Its Drinfeld centre is a modular fusion category. The S-matrix is invertible, and
   dim Z(C) = dim(C)² (`Centre*`, `Modular`).
3. Property F gives finite-order twists and monodromies (Vafa-type arguments), and integrality of the
   symmetric core (`Cabling`, `Calculus`, `CentreCabling`, `CentreCalculus`).
4. A Galois rigidity argument on the S-matrix concludes that FPdim(C) is an integer (`Integrate`, `Final`).

## Building

Lean and Mathlib are pinned to `v4.35.0`.

```sh
lake exe cache get
lake build
```

`scripts/check.sh` checks that the audit modules import the whole library and then builds it.
`scripts/audit-target.sh` builds the target audit, which rejects `sorry`, extra axioms and unsafe
declarations in the dependency cone of the final theorem, and prints its axioms.
