# Anyon Atlas Lean interface

`Raw.lean` represents exact modular-data entries as rational combinations of roots of unity.
`Sample.lean` checks the rank-one sample against the proved trivial modular datum.

The source is [The Anyon Atlas](https://anyonatlas.org/), described in
[arXiv:2610.25439](https://arxiv.org/abs/2610.25439).
A modular-data record alone does not establish categorification or property F.
The numerical download, query and validation tools have been removed to keep
this repository focused on Lean proofs.
